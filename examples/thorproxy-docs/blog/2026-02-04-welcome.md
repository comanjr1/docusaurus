## Key Features

### 🌍 Global Coverage
Access residential IPs from over 195 countries:
- **Indonesia**: Telkomsel, Indihome, XL Axiata, Biznet, First Media
- **United States**: Comcast, Verizon, AT&T
- **United Kingdom**: BT, Virgin Media, Sky Broadband
- **Germany**: Deutsche Telekom, Vodafone
- **Japan**: NTT, KDDI, SoftBank

### 🔄 Flexible Rotation
Choose from multiple rotation strategies:
- **Per-request rotation**: New IP with every request
- **Timer-based**: Rotate every 1, 5, 10, or 30 minutes
- **Sticky sessions**: Keep the same IP for session-based tasks

### 📊 Precise Targeting
Target your exact needs:
- **Country-level**: Select specific countries
- **City-level**: Choose IPs from specific cities
- **ISP-level**: Filter by internet service provider
